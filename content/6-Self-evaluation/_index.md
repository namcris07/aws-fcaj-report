During my internship in the **First Cloud AI Journey (FCAJ)** program from **June 15, 2026** to **August 14, 2026**, I had the invaluable opportunity to learn, practice, and apply cloud computing and DevOps engineering methodologies into a practical project environment.  

Throughout the internship, I collaborated with my team to deliver the project **"DevSecOps Factory: End-to-End Automated CI/CD Pipeline on Amazon ECS Fargate"**. Through this hands-on endeavor, I significantly developed technical skillsets, including: designing AWS VPC networking, managing private container registries via Amazon ECR, building a 22-stage Jenkins pipeline with 6 Security Gates (Gitleaks, Trivy SCA, SonarQube, Checkov, Trivy Image, OWASP ZAP), automating security finding aggregation using AWS Lambda & S3, deploying serverless container workloads on Amazon ECS Fargate, monitoring application health via CloudWatch Container Insights, as well as honing technical documentation and teamwork capabilities.
